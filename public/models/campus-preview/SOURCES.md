Terms: https://portal.csdi.gov.hk/csdi-webpage/doc/TNC

The path overlay is a selection from the Lands Department 3D Pedestrian Network in EPSG:2326. Coordinates are unchanged except for origin translation and the glTF axis convention. Whole source lines intersecting the display envelope are included; they are not snapped or artificially connected. Widths are symbolic. Viewing through buildings is an optional overlay, not evidence of a traversable corridor.

The exterior assets are exported from the existing Blender preview. Surrounding display extent is cropped, JPEG textures are reduced to 1024 pixels, and untextured source buildings use display colours. Source data is of mixed dates. Building-name correspondences are candidates, not verified entrance locations. Object counts include terrain, infrastructure and surrounding buildings, and do not mean that many HKU buildings.

No interior-room geometry, HKU reference floorplan images, secrets, or user position data is included in this export. This preview is not a complete campus model, verified door-routing graph, or operational navigation system. Source data is provided as-is without warranty; check site access and conditions independently.

The existing navigation demo at the parent URL is preserved and has its own source/accuracy limitations.

For browser display the legacy FBX materials are treated as non-metallic diffuse surfaces (roughness 0.9), avoiding an inappropriate metallic appearance; original image maps are retained.
