# 觅径 · 室内导航实验室

## 香港大学本部大楼 v5（2026-09-07）

[打开在线演示](https://hyf0225.github.io/mi-jing-indoor-navigation/)，选择「香港大学本部大楼」，点击「全楼 / 楼层剖切 / 校园场景」。

- 提供带材质的校园场景、2/F 上层剖切、独立 1/F 图纸模型、G/F 地面层剖切。
- 地形、道路、邻近建筑和树木为参考实景与官方校园图制作的估算场景；G/F、2/F 共 48 个新增房间为示意布局，不是真实房号或办公室分配。
- 目的地模拟导航仍限于 1/F 已定位的 17 个教室门口，未验证真实门禁与开放状态；不会把推定上层接入导航。
- 路线播放支持俯视/人视切换、倍速、轻量地面指引与可定制人物向导。
- 模型首次加载需要下载较大的 GLB 文件，请稍候。来源与限制见 [模型说明](public/models/HKU-MAIN-BUILDING-SOURCE.md)。

完整校验：`pnpm exec tsc --noEmit`、`pnpm test`、`PAGES_BASE_PATH=/mi-jing-indoor-navigation pnpm build:pages`。

使用网上下载的 OpenVGAL 单层展厅和 Empty Mall 三层商场，验证「选择建筑 → 目的地搜索 → 多路线 → 三维预览/视频 → 位置与朝向确认 → 分段指引 → 到达/错路恢复」。不是照片重建服务，也不使用连续定位。

当前外观：黑色数字空间主题，深色操作面板、青蓝导航标记、模型几何轮廓和空间网格。原始下载模型保持不变。

## GitHub 与长期保存

同一套导航组件支持两种构建：`pnpm build` 用于当前私有 Sites 页面；`pnpm build:pages` 生成独立静态页面，无需 Sites 服务、后端或 API Key。详细部署与迁移步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

GitHub Pages 的仓库子路径由 `PAGES_BASE_PATH` 配置，模型、许可、脚本和样式都使用对应前缀。目录与演示模型、许可文件应一起保存，不能只保存网页截图或单个 HTML。

## 运行与检查

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm exec tsc --noEmit
node --experimental-strip-types --test tests/navigation.test.mjs
pnpm build
```

需要支持 TypeScript 类型擦除的 Node.js。浏览器需支持 WebGL；视频生成还需要 canvas.captureStream 和 MediaRecorder，自动选择可用的 WebM/MP4 编码。无需 API Key，无外部付费模型调用。

## 实现位置

- `app/buildings.ts`：建筑注册表与统一数据契约；新增方式见 [BUILDINGS.md](BUILDINGS.md)。
- `app/building-navigation.ts`：共用的 Dijkstra / 有界 Yen 候选路算法、三维路径采样、跨层连接与路线约束。
- `app/empty-mall.ts`：三层商场数据，65 个路径节点、69 条边；非确认中间点用于真实扶梯折线及门洞绕行。
- `app/navigation.ts`：原展厅数据与回归测试基线。
- `app/playback.ts`：可测试的暂停 / 继续计时器，暂停不清零；另设从头重播。
- `app/gallery-viewer.tsx`：加载 GLB、剖视/人视、路线标记、四朝向截图、约 18 秒的路线视频。
- `app/page.tsx`：搜索、多路线、路口确认、到达、恢复、封路、视频播放/下载与临时日志。
- `tests/navigation.test.mjs`：16 项导航、跨楼层、资产一致性与播放计时检查。
- `public/models/SOURCE.md`、`OPENVGAL-LICENSE.txt`：来源、固定版本、哈希、修改方式与 MIT 原始许可。

## 演示边界

这是作者制作的约 30×60 模型单位的虚拟展厅，不是真实博物馆的扫描。原始 GLB 1,702,044 bytes（1.62 MiB），下载文件保持原样；渲染时隐藏辅助对象、俯视隐藏屋顶、简化照明并调整材质。展区、导航节点、标识和方位为演示标注。

现行共用图算法使用 Dijkstra + 最多 12 条 Yen 候选路径，展示最多 3 条合理路线。绕行不超过最短路线的 1.75 倍，且额外距离不超过 35 模型单位，不为凑数强行提供三条。千节点以上规模仍需专门性能评估、空间配准和运营管理。

新增 Empty Mall 由 loafbrr 制作、CC BY 4.0 许可，通过 Objaverse 下载；原始文件 3,456,400 字节不变。它有三层楼板、中庭、真实建模的扶梯和店铺隔墙，但并非经证实的现实建筑扫描。参见 [署名与来源](public/models/EMPTY-MALL-SOURCE.md)。商场路线沿原扶梯几何连接，未捏造电梯；选择避开扶梯与楼梯时，跨层无可用路线会明确提示。同层几何检查不构成现实无障碍或通行安全认证。

距离是模板名义尺度估算，未作现场测量。路线端点停在室内门前；原始模型两端装饰门后的墙没有开口，因此不规划穿墙出入。碰撞检查针对本模型的四片隔板和外墙，不能代表任意建筑的通行或无障碍验证。

确认点之间只显示最后一次确认的位置，不假定用户跟随预览移动。切换目的地、重新选路线及封路重算时使用最后确认位置。照片卡片是模型渲染截图，不是实景照片。视频是当前路线的渲染快照，不自动随之后的路线变化更新。视频、状态和日志仅在当前页面内存中保留，刷新后清空；用户可自行下载视频。

切换建筑会清空旧建筑的路线、确认位置、视频预览进度、已生成视频和临时日志，避免跨建筑串用。暂停预览再继续保留原进度；改路线、改视角、重新确认位置、显式重播会重新初始化预览。下载后的视频使用播放器自己的暂停 / 继续功能。

未实现：真实照片重建、自动视觉定位、真实电梯运行信息、地图编辑后台、实时通道信息、陌生用户实走验证。
